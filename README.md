# Generazione di uno script Python tramite strumenti di IA

L'obiettivo di questo progetto è dimostrare che, in alcuni casi, la scrittura di script algoritmici complessi può essere automatizzata utilizzando strumenti di Intelligenza Artificiale (IA).

## Contesto del progetto

In questa occasione, riprendiamo un problema presentato inizialmente nel 2020 nel corso “Python Flask 2020” disponibile su Developpez.com.

Questo corso si basava su un **calcolo fiscale semplificato per l’anno 2019**. All’epoca, per risolvere questo problema era stato sviluppato manualmente uno script Python, poi adattato in 18 versioni diverse, prima di essere infine implementato in un’applicazione web MVC.

## Obiettivo

L’obiettivo è dimostrare che, nel settembre 2025, lo script iniziale di calcolo delle imposte può essere generato direttamente da alcuni sistemi di IA generativa, ma non da tutti.

## Strumenti di IA testati

Per questo esperimento (settembre 2025) sono stati utilizzati i seguenti sette strumenti:

* ChatGPT
* Grok
* Gemini
* MistralAI
* DeepSeek
* ClaudeAI
* Perplexity
